### 👋 Привет! Мы — Edemium

Внедряем ИИ в бизнес **под P&L**: не «технологии ради технологий», а решения, которые окупаются.
Аудит процессов → пилот с измеримым KPI → ведение после запуска. Работаем напрямую с основателем.

### 🧩 Что делаем

| | Направление | Для чего |
|:-:|---|---|
| 🤖 | **ИИ-агенты** | Автоматизация рабочих процессов и рутины |
| 💬 | **Чат-боты** | Продажи и поддержка клиентов в мессенджерах |
| 📞 | **Голосовые боты** | Входящие звонки и обзвон с живым голосом |
| 📊 | **Речевая аналитика** | Качество диалогов, причины потерь, контроль менеджеров |
| ⚙️ | **Внедрение ИИ под ключ** | От аудита до работающего решения |

### 🛠 Как работаем

```text
1. Аудит        →  находим, где ИИ даст деньги, а где нет
2. Пилот        →  запуск на ваших данных с понятной метрикой
3. Поддержка    →  ведём решение после запуска и растим результат
```
